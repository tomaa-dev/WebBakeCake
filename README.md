# CakeBake — конструктор тортов на заказ

Веб-приложение для заказа тортов по индивидуальному дизайну. Пользователь собирает торт из доступных опций (уровни, форма, топпинг, ягоды, декор), указывает адрес и время доставки, а готовый заказ уходит менеджеру.


## Как установить
Операционная система: любая, где доступен Python 3 (Windows, macOS, Linux). Используем 'pip' для установки зависимостей (requests, python-dotenv):

```
pip install -r requirements.txt
```

Рекомендуется использовать virtualenv/env для изоляции проекта.

Примеры запуска программы:

```
python manage.py runserver
```

## Загрузка справочных данных

Чтобы заполнить справочники (уровни, формы, топпинги, ягоды, декор), нужно выполнить команду:
```
python manage.py loaddata cakes/fixtures/options.json
```

## Переменные окружения
Программа использует нестандартные переменные окружения для настройки. Эти переменные не могут быть автоматически обнаружены и должны быть указаны в файле `.env` перед запуском программы.

**SECRET_KEY** - Секретный ключ Django (Например, django-insecure-rl%#vtv%o4r3j_dz-3wjjbvm36+avv5k0x-ht622q3^4op8).

**DEBUG** - Режим отладки.
