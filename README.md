# WebBakeCake — конструктор тортов на заказ

Веб-приложение для заказа тортов. Пользователь выбирает готовый торт из каталога
или собирает свой из опций (уровни, форма, топпинг, ягоды, декор, надпись),
указывает адрес и время доставки. Заказ сохраняется в базе, отображается в
личном кабинете и доступен в админке Django.

## Требования

- Python 3.12
- SQLite — база `db.sqlite3` создаётся автоматически, отдельно настраивать нечего

Зависимости лежат в `requirements.txt`:


## Быстрый старт

### 1. Виртуальное окружение

Windows, PowerShell:

```
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Linux, macOS:

```
python3 -m venv venv
source venv/bin/activate
```

Если PowerShell блокирует активацию скриптов, можно не активировать окружение
и запускать всё через `.\venv\Scripts\python.exe manage.py ...`.

### 2. Зависимости

```
pip install -r requirements.txt
```

### 3. Переменные окружения

Скопируйте пример в рабочий файл — без `SECRET_KEY` приложение не запустится:

```
copy .env.example .env     # Windows
cp .env.example .env       # Linux, macOS
```

### 4. База данных

```
python manage.py migrate
```

### 5. Справочные данные

Заполнить каталог готовых тортов и справочники опций:

```
python manage.py loaddata cakes/fixtures/options.json
python manage.py loaddata cakes/fixtures/cakes.json
```

### 6. Учётная запись администратора

Нужна, чтобы смотреть заказы в админке:

```
python manage.py createsuperuser
```

### 7. Запуск

```
python manage.py runserver
```

Сайт откроется на `http://127.0.0.1:8000/`.

## Переменные окружения

Все четыре читаются в `bake_cake/settings.py` через `environs`, значения берутся
из `.env`.

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `SECRET_KEY` | да | нет | Секретный ключ Django. Без него приложение не стартует |
| `DEBUG` | нет | `True` | Режим отладки. На боевом сервере выставить `False` |
| `ALLOWED_HOSTS` | нет | `127.0.0.1,localhost` | Список доменов через запятую, без пробелов |
| `WEB_URL` | нет | `http://127.0.0.1:8000` | Адрес сайта. Используется для ссылок на метки в админке |

## Маршруты

| Адрес | Назначение |
| --- | --- |
| `/` | Главная: каталог готовых тортов, конструктор, шаги заказа |
| `/lk/` | Личный кабинет: профиль и история заказов |
| `/lk/profile/` | Изменение имени и почты |
| `/reg/` | Регистрация по номеру телефона, в два шага: номер, затем код |

| `/order/` | Приём заказа, только POST и только для вошедшего |
| `/admin/` | Админка Django |

## Регистрация и заказ

Вход по номеру телефона: пользователь вводит номер, соглашается на обработку
персональных данных и вводит код подтверждения. Согласие фиксируется в профиле
вместе с датой, версия текста хранится в `CONSENT_VERSION`.

**Код подтверждения сейчас не отправляется по SMS.** Он генерируется на сервере и
показывается сообщением на странице — это демо-режим, `cakes/views.py:132`. Перед
боевым запуском отправку нужно реализовать.

Оформить заказ может только зарегистрированный пользователь: `/order/` закрыт
декоратором `@login_required`, а неавторизованного отправляет на регистрацию.
Из-за этого у каждого заказа есть владелец, и заказы видны в личном кабинете.

После регистрации выбор торта сбрасывается: пользователь возвращается на главную
и выбирает заново. Выбранные опции живут только в памяти браузера.

## Правила расчёта цены

Константы в начале `cakes/models.py`:

| Константа | Значение | Смысл |
| --- | --- | --- |
| `INSCRIPTION_PRICE` | 500 | Надпись на торте, добавляется к цене |
| `URGENT_HOURS` | 24 | Порог срочности в часах |
| `URGENT_PERCENT_PRICE_INCREASE` | 20 | Надбавка в процентах |

Надбавка за срочный заказ начисляется, когда доставка раньше чем через
`URGENT_HOURS` часов от текущего момента. Считает `Order.set_price()`.


## Тесты и линтеры

Тесты:

```
python manage.py test cakes
```

Линтеры лежат в `requirements-dev.txt`, их нужно доставить отдельно от
`requirements.txt`:

```
pip install -r requirements-dev.txt
```

После этого доступны проверки, которыми пользуется CI:

```
black --check .
isort --check-only --diff .
flake8 .
```

Настройки всех трёх — в `pyproject.toml`: длина строки 119, миграции
исключены из форматирования. Проверки запускаются в GitHub Actions на каждом
pull request и на push в `main`; тесты Django в CI не входят, их нужно гонять
локально.

## Структура проекта

```
bake_cake/     настройки Django, urls, wsgi
cakes/         приложение: models, views, forms, admin, fixtures
templates/     index.html — главная, lk.html — личный кабинет
static/        css, js, favicon
```

Шаблонов ровно два, общая база не используется — каждая страница самодостаточна.

## Развёртывание за обратным прокси

В настройках прописан `SECURE_PROXY_SSL_HEADER`, поэтому `X-Forwarded-Proto`
понимается корректно и за прокси достаточно передавать этот заголовок.
`DEBUG` на боевом сервере должен быть `False`, а `ALLOWED_HOSTS` — содержать
реальные домены.
