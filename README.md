# WebBakeCake - конструктор тортов на заказ

Веб-приложение для заказа тортов. Пользователь выбирает готовый торт из каталога
или собирает свой из опций (уровни, форма, топпинг, ягоды, декор, надпись),
указывает адрес и время доставки. Заказ сохраняется в базе, отображается в
личном кабинете и доступен в админке Django.

## Требования

- Python или Python3 должен быть установлен. Проверенная версия - 3.12.

## Быстрый старт

### 1. Виртуальное окружение

Windows, PowerShell:

```
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Linux, macOS:

```
python3 -m venv venv
source venv/bin/activate
```

### 2. Зависимости

```
pip install -r requirements.txt
```

### 3. Переменные окружения

Создайте файл .env по примеру .env.example:

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `SECRET_KEY` | да | нет | Секретный ключ Django. Без него приложение не стартует |
| `DEBUG` | нет | `True` | Режим отладки. На боевом сервере выставить `False` |
| `ALLOWED_HOSTS` | нет | `127.0.0.1,localhost` | Список доменов через запятую, без пробелов |
| `WEB_URL` | нет | `http://127.0.0.1:8000` | Адрес сайта. Используется для ссылок на метки в админке |


### 4. База данных

```
python manage.py migrate
```

### 5. Справочные данные

Заполнить каталог готовых тортов и справочники опций:

```
python manage.py loaddata cakes/fixtures/options.json
python manage.py loaddata cakes/fixtures/cakes.json
```

### 6. Учётная запись администратора

Нужна, чтобы смотреть заказы в админке:

```
python manage.py createsuperuser
```

Логином является номер телефона в формате +7.

### 7. Запуск

```
python manage.py runserver
```

Сайт откроется на `http://127.0.0.1:8000/`.


## Регистрация и заказ

Вход по номеру телефона: пользователь вводит номер, соглашается на обработку
персональных данных и вводит код подтверждения. Согласие фиксируется в профиле
вместе с датой.

**Код подтверждения сейчас не отправляется по SMS, а показывается на странице.** 

Оформить заказ может только зарегистрированный пользователь.


## Линтеры

Линтеры лежат в `requirements-dev.txt`, их нужно доставить отдельно от
`requirements.txt`:

```
pip install -r requirements-dev.txt
```

После этого доступны проверки, которыми пользуется CI:

```
black --check .
isort --check-only --diff .
flake8 .
```

Настройки всех трёх - в `pyproject.toml`: длина строки 119, миграции
исключены из форматирования.


## Развёртывание за обратным прокси

В настройках прописан `SECURE_PROXY_SSL_HEADER`, поэтому `X-Forwarded-Proto`
понимается корректно и за прокси достаточно передавать этот заголовок.
